# BaitCheck

**Less Hype | More Proof**

Life is short, and YouTube has a bottomless supply of thumbnails promising life-changing revelations. BaitCheck checks the video’s claims against its transcript, summarizes the evidence, and gives you a Bullshit Index so you can decide whether to watch, skim, or skip. Less hype. Fewer wasted minutes. No need to sit through a 20-minute video to find out the “secret” was a sponsored mattress.

## Install the Shortcut

[Download BaitCheck](https://www.icloud.com/shortcuts/93709a3cb3544a3481f0aef37f058566)

## Requirements

- iPhone or iPad with Apple Intelligence and an available Cloud Pro or equivalent model in Shortcuts
- YouTube Data API v3 key to retrieve video titles and descriptions
- Supadata API key to retrieve video transcripts

## Get API Keys

- YouTube Data API v3: https://console.cloud.google.com/
- YouTube API setup guide: https://developers.google.com/youtube/data/getting-started
- Supadata: https://dash.supadata.ai/
